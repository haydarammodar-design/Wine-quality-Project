# AI usage
## Study material: Claude (Anthropic), via Claude Code, 27 October 2026
We gave the tool the project subject and asked it for study material. It produced:
- a study guide (PDF) explaining every concept and tool used in the project (pipelines,
  ColumnTransformer, cross-validation, GridSearchCV, metrics, threshold, interpretation,
  classes, configuration, argparse, pytest, ruff, Git), and a step-by-step guide to building
  the project, including explained example code for each module and test;
- a tutorial notebook describing each step, with empty cells for us to fill in.
How we used it: we studied the guide, then wrote the package, the tests, the notebook, the
report and the slides ourselves in our repository, typing and running the code step by step.
We can explain every line.

## Debugging and setup: Claude Code, 28 October 2026
We also used Claude Code in our repository to find and fix errors in our code (syntax and
indentation errors, broken docstrings, a mistyped import, an invalid `pyproject.toml`), to align
modules with the guide's interfaces, to write the test files from the guide's section 10, to
fill in the README structure, and to make and push the Git commits. We reviewed every change
and can explain it.
